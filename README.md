# Egyptian News RAG Q&A 🇪🇬📰

## Overview

This project provides a question-answering system focused on Egyptian news articles. It combines a web scraper to gather recent news from various Egyptian sources and a Retrieval-Augmented Generation (RAG) application built with LangChain and Google Gemini to answer user questions based on the collected news data. The interface is presented using Streamlit.

The system includes two main components:

1.  **`scraper.py`:** A Python script that scrapes news articles (titles, dates, content) from multiple Egyptian news websites (e.g., Youm7, Al-Ahram, Masrawy, etc.). It handles Arabic text normalization and saves the data in JSON and CSV formats.
2.  **`app.py`:** A Streamlit application that:
    *   Loads the scraped news data.
    *   Uses LangChain to chunk the data, generate embeddings (via Google Generative AI), and store them in a Chroma vector database.
    *   Implements a RAG pipeline using Google Gemini 1.5 Pro to answer user questions in Arabic or English, based *only* on the retrieved news context.
    *   Includes a fallback mechanism to use Gemini's general knowledge if no relevant information is found in the news database.
    *   Features rate limiting and caching to manage API usage efficiently.

## Features

*   **Multi-Source Scraping:** Gathers news from several major Egyptian news portals.
*   **RAG Implementation:** Answers questions based on retrieved relevant news snippets using LangChain and Gemini.
*   **Vector Database:** Uses Chroma for efficient similarity search over news article chunks.
*   **LLM Integration:** Leverages Google Gemini 1.5 Pro for embedding generation and question answering.
*   **Bilingual:** Supports questions and answers in both Arabic and English.
*   **Fallback Mechanism:** Provides general answers via Gemini if the specific information isn't in the scraped news.
*   **Streamlit UI:** Interactive web interface for easy interaction.
*   **API Optimization:** Includes rate limiting and response caching to minimize Gemini API calls.
*   **Data Persistence:** Saves scraped data and the vector database locally.

## How it Works

1.  **Scraping (`scraper.py`):**
    *   The scraper visits configured Egyptian news websites.
    *   It extracts article links from main sections and paginated pages.
    *   It scrapes the title, date, and content of individual articles.
    *   Arabic text is stored without display processing (suitable for NLP tasks).
    *   Collected articles are saved into a specified directory (default: `egyptian_news_dataset`) as JSON/CSV files.
2.  **RAG Application (`app.py`):**
    *   Loads the JSON data generated by the scraper.
    *   Converts articles into LangChain `Document` objects.
    *   Splits documents into smaller chunks using `RecursiveCharacterTextSplitter`.
    *   Generates embeddings for each chunk using `GoogleGenerativeAIEmbeddings`.
    *   Builds (or loads) a persistent `Chroma` vector store from the embeddings.
    *   When a user asks a question via the Streamlit interface:
        *   The system detects the language (Arabic/English).
        *   It retrieves the most relevant document chunks from Chroma based on the query.
        *   A prompt containing the user's question and the retrieved context is sent to the Gemini 1.5 Pro model (`ChatGoogleGenerativeAI`).
        *   Gemini generates an answer based *only* on the provided context.
        *   *If no relevant context is found*, a separate prompt asks Gemini to answer based on its general knowledge.
        *   The answer is displayed in the Streamlit chat interface.
        *   Rate limits and caching are applied to manage API calls.

## Requirements

*   Python 3.x
*   A Google Gemini API Key (obtainable from [Google AI Studio](https://aistudio.google.com/)).

## Installation

1.  **Clone the repository (or save the scripts):**
    If this is in a repository:
    ```
    git clone <your-repository-url>
    cd <repository-directory>
    ```
    If you have the scripts separately, save them as `scraper.py` and `app.py` in a new directory.

2.  **Create a `requirements.txt` file** with the following content (combining dependencies from both scripts):
    ```
    streamlit
    google-generativeai
    langchain
    langchain-community # Includes Chroma
    langchain-google-genai
    chromadb
    python-dotenv
    requests
    beautifulsoup4
    pandas
    arabic_reshaper
    python-bidi
    pyarabic # For text normalization in scraper
    # Add any other specific versions if needed
    ```

3.  **Create a virtual environment (recommended):**
    ```
    python -m venv venv
    # On Windows
    venv\Scripts\activate
    # On macOS/Linux
    source venv/bin/activate
    ```

4.  **Install the required libraries:**
    ```
    pip install -r requirements.txt
    ```

## Configuration

1.  **Scraper:**
    *   The scraper saves data to the `egyptian_news_dataset` directory by default. You can change this in the `EgyptianNewsScraper` initialization within `scraper.py`.
    *   You can configure which websites to scrape and how many articles/pages per section in the `scraper.run()` call at the end of `scraper.py`.
2.  **RAG Application:**
    *   The Streamlit app expects the scraped data in the `egyptian_news_dataset` directory by default. You can change this via the sidebar input in the Streamlit UI or modify the default in `EgyptianNewsRAG` initialization within `app.py`.
    *   The vector store is saved to the `egyptian_news_vectorstore` directory by default.
    *   You need to provide your Google Gemini API key via the sidebar input in the Streamlit UI when you run the app. The app does *not* use a `.env` file directly based on the provided code, relying instead on the Streamlit input or environment variables set externally.

## Usage

1.  **Run the Scraper:**
    *   First, you need to collect the news data. Run the scraper script:
        ```
        python scraper.py
        ```
    *   This will create the `egyptian_news_dataset` directory (or your configured directory) and populate it with JSON/CSV files containing the scraped news. This may take some time depending on the number of websites and articles configured.

2.  **Run the RAG Application:**
    *   Once the scraping is complete, run the Streamlit application:
        ```
        streamlit run app.py
        ```
    *   The application will open in your web browser.
    *   Enter your Google Gemini API key in the sidebar.
    *   Verify the "Data Directory" path points to where the scraper saved the files (e.g., `egyptian_news_dataset`).
    *   Click "Initialize System". This will load the data, create embeddings, and build the vector store (this might take time on the first run).
    *   Once initialized, you can ask questions about Egyptian news in the chat input field in either Arabic or English.
